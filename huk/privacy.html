Privacy policy

Last updated: 8 November 2026.

Huk is a personal assistant used only by its owner, Yurii Holiuk. The only Google account it accesses is the owner's own.

Data accessed

With the owner's explicit consent, Huk accesses Gmail messages and labels (to search, read and organise the owner's mail and create drafts) and read-only YouTube account data (subscriptions, playlists, liked videos).

How it is used and stored

The data is used only to answer the owner's requests. It is processed on the owner's own server. OAuth tokens are stored encrypted. Data is not sold, not shared with third parties, not used for advertising, and not used to train generalised AI or machine learning models.

Huk's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions; the stored token is then deleted.
